OmniLab Terms

Current public release

Use the lab as a learning tool.

These terms describe the current public release of OmniLab, an interactive simulator that returns educational reaction information for supported chemical pairs.

Updated July 17, 2026

The short version

  • The current public release is free and requires no account.
  • Reaction results are educational predictions, not verified lab results.
  • The public source code is available under the MIT License.

Educational use

OmniLab lets you explore predicted chemical reactions using a virtual workspace. Returned equations, explanations, effects, and safety guidance simplify real chemistry and can be incomplete for a particular physical setup. Verify important information with trusted sources and follow the rules, supervision, and safety procedures of any real laboratory.

Responsible use

Don't use OmniLab as a substitute for professional judgment or as permission to conduct a real reaction. Don't interfere with the service, attempt to bypass its safeguards, or submit personal, confidential, or identifying information through the chemical input.

Availability and changes

The current public release is provided without an account or payment flow. Features, reaction results, availability, and the terms for a future release may change. The pricing page states the current public offer.

Open-source software

OmniLab's public source code is licensed under the MIT License. That license permits use, copying, modification, and distribution of the software and provides the software "as is," without warranty.
